# 操作说明书

## 一、软件简介

本软件用于铁路车辆制动性能的教学演示和简化计算。用户可以输入车辆与线路参数，计算响应距离、制动距离、总停车距离、制动时间和减速度，并查看速度—时间或速度—距离曲线。新版本提供“演示当前参数”动画、失控检测报告、合成数据 CNN 教学演示，以及基于公开轴承振动数据训练的轴承状态分类模型。软件支持导入多个 CSV 工况并导出计算结果。

本软件采用单车辆、恒定制动率和恒定基本运行阻力系数的简化模型。计算结果不能替代铁路车辆设计校核、运营规程或安全决策。

## 二、运行环境

- 源代码版本：
1. Windows、macOS 或 Linux。
2. Python 3.10 或更高版本。
3. Tkinter：Python 图形界面标准库。Windows 官方 Python 安装通常包含 Tkinter。
4. NumPy：用于数值计算和 1D 卷积网络训练。
5. SciPy：用于读取 MATLAB 振动数据和抗混叠降采样。
6. Matplotlib：用于显示曲线。


- 发布版本：

   Windows x86

## 五、主界面组成

1. “车辆与工况参数”：输入工况名称、车辆质量、初速度、制动率、响应时间、线路坡度、基本运行阻力系数、旋转质量换算系数和轮轨黏着系数。
2. “计算结果”：显示成功计算的工况及减速度、响应距离、制动距离、总停车距离、制动时间和总时间。
3. “曲线分析”：选择一个计算成功的工况，并在速度—时间与速度—距离曲线之间切换。
4. 按钮：
   - “计算当前参数”：只计算参数输入区当前的一组工况。
   - “演示当前参数”：根据当前参数播放车辆运动动画，结束后显示失控检测报告。
   - “预测车辆状况（演示）”：现场生成虚构时序样本并训练 1D 卷积网络，输出合成等级和免责声明。
   - “识别轴承状态（实测数据模型）”：选择 `.mat` 振动文件，使用已训练模型分类轴承状态。
   - “导入 CSV 工况”：读取 CSV 文件并批量计算其中的工况。
   - “导出计算结果”：将当前成功计算的工况结果保存为 CSV。
   - “恢复默认值”：恢复参数输入框的示例值，并清空当前结果。

## 六、参数说明与输入规则


| 参数名称 | 含义及单位/范围 |
|:---:|:---:|
| 工况名称 | 非空文本|
| 车辆质量 | kg，必须大于 0 |
| 初速度 | km/h，必须大于或等于 0 |
| 制动率 β | 无量纲，范围为 (0, 1] |
| 制动响应时间 | s，必须大于或等于 0 |
| 线路坡度 | ‰；上坡为正，下坡为负 |
| 基本运行阻力系数 | 无量纲，必须大于或等于 0 |
| 旋转质量换算系数 | 无量纲，必须大于或等于 0 |
| 轮轨黏着系数 μ | 无量纲，范围为 (0, 1] |

所有数值均须为有限数值。制动率 β 大于黏着系数 μ 时，该工况不计算。对于计算减速度不大于 0 的正速度工况，软件提示无法在当前模型下停车，不会给出停车结果。

## 七、单工况计算步骤

1. 在参数区填写工况名称和车辆、制动、线路参数。
2. 确认坡度符号约定：上坡输入正值，下坡输入负值。
3. 点击“计算当前参数”。
4. 如果输入不合法，软件会弹出参数错误提示；按提示修改后重新计算。
5. 计算成功后，在结果表查看数值，并在曲线分析区选择曲线类型。
6. 如需保存，点击“导出计算结果”，选择保存位置和文件名。

软件启动时已预填一组示例参数。用户可直接点击“计算当前参数”体验功能。

## 八、失控检测与动画演示

1. 在参数区填写当前工况，点击“演示当前参数”。
2. 新窗口会播放车辆在响应阶段及制动阶段（或持续运行阶段）的运动示意。动画为压缩时长的模拟，并非实时物理仿真。
3. 动画结束后，窗口底部“失控检测报告”列出检测结论、参数依据、等效减速度和动画终态。
4. 检测限定为两项简化规则：
   - 当制动率 β 大于黏着系数 μ 时，报告黏着受限/滑移风险，并按 μ 限制有效制动率后演示。
   - 当正初速度下按黏着限制修正后的等效减速度不大于 0 时，报告当前坡度与制动能力组合下不能停车，并演示车辆继续运行。
5. 其他通过上述简化检查的工况报告“模型内可控停车”。初速度为零时报告静止状态。
6. 如果参数超出数值计算范围，程序显示错误而不启动动画。动画只作教学示意，不能证明真实车辆安全或失控。

## 九、合成 CNN 车辆状况预测

1. 输入一组当前工况，点击“预测车辆状况（演示）”。
2. 程序生成 2,400 条合成时序数据，在后台训练一个 1D 卷积分类器；训练期间窗口显示状态，完成后显示模型结果。
3. 报告包含合成分类等级、模型 softmax 输出、合成负荷指数、合成留出集准确率、训练样本数和类别阈值。
4. 当前四个标签为“合成常规工况”“合成部件载荷升高”“合成耐受极限超出”和“合成极端整体失效类别（非真实散架预测）”。极端标签只代表本软件构造的虚构类别，不代表真实部件或车辆会受损、断裂或散架。
5. 合成负荷指数按质量、速度平方、制动率、坡度绝对值和制动率/黏着系数的示例公式计算。分类边界为 0.75、1.35 和 2.50，仅用于生成合成训练标签，不是工程耐受限值。
6. 准确率只在同一套合成规则生成的留出数据上统计，不代表真实车辆预测能力；softmax“置信度”也不是实际损坏概率。
7. 该演示不使用真实车辆、部件材料、试验、有限元或维修数据，不可用于确定零件耐受极限、实际损伤状况或车辆散架风险。

## 十、公开数据集轴承状态识别

1. 在主界面点击“识别轴承状态（实测数据模型）”，选择一份包含 `Channel_1` 加速度通道的 MATLAB `.mat` 文件。
2. 程序按训练时相同的预处理步骤分析振动信号，并输出五类状态的平均 softmax 分数。分数仅用于比较模型输出，不是经校准的故障概率。
3. 训练数据来自 Mendeley Data 数据集 `Bearing Vibration Data under Time-varying Rotational Speed Conditions`，版本 2，DOI：10.17632/v43hmbwxpm.2，许可为 CC BY 4.0。作者为 Huan Huang、Natalie Baddour，机构为 University of Ottawa。原始数据约 200 kHz、每条记录 10 秒，包括加速度 `Channel_1` 和编码器转速 `Channel_2`；本模型只使用 `Channel_1`。来源与署名方式见 `data\mendeley_bearing_v2\ATTRIBUTION.txt`。
4. 数据集共有 60 条记录：健康、内圈故障、外圈故障、滚动体故障和复合故障五类，各有四种变速工况、每工况三次试验。本项目只选取 A（转速递增）工况的五类 × 三次试验，共 15 条；类别由来源文件名前缀标注。未使用其它变速工况，因此模型不应被视为覆盖全数据集或任意转速。
5. 训练前处理：`Channel_1` 经抗混叠多相滤波降采样 10 倍到 20 kHz；切成 512 点窗口（25.6 ms），窗口起点间隔 2048 点（102.4 ms，稀疏取窗而非重叠窗口）。每窗生成两个通道：去均值并按该窗 RMS 归一化的波形，以及 `log10(RMS)` 强度特征。两个通道随后按训练集整体均值、标准差标准化；验证集不参与归一化参数估计。
6. 数据划分以完整原始试验为单位：每类试验 01、02（10 条记录，共 980 个窗口）训练；每类试验 03（5 条记录，共 490 个窗口）留出验证。不会把同一原始试验切出的窗口同时分到训练集和验证集。验证仍来自相同装置、变速工况和实验环境，并非跨设备或跨工况验证。
7. 网络为 NumPy 手写的 1D CNN：宽度 5 的卷积核、12 个卷积滤波器、ReLU、全局平均池化、全连接层及 softmax 五分类输出。交叉熵梯度通过反向传播更新卷积层和全连接层；以 64 个窗口为一批，训练 80 轮，训练批次每轮打乱。初始化和批次顺序使用固定随机种子，便于复现此课程实验。
8. 本次留出验证准确率为 62.86%（308/490）。混淆矩阵、各类别 precision/recall 和运行配置见 `轴承CNN训练报告.txt`。其中复合故障 recall 为 36.73%，说明当前模型有明显漏判；单次划分的指标仅描述本次实验，不能视为稳定的泛化性能。
9. 如需重新下载训练样本并训练模型，在 `newvers` 目录运行：
   python train_bearing_cnn.py
   下载器会先核验官方元数据及 CC BY 4.0 许可，再按官方 SHA-256 校验下载文件。数据保存在 `data\mendeley_bearing_v2\`，模型权重写入 `models\bearing_condition_v2.npz`，评估结果写入 `轴承CNN训练报告.txt`。构建 EXE 时嵌入训练好的权重，不会将 15 条原始 MATLAB 文件打入 EXE。
10. 该数据是实验台轴承记录，不是铁路车辆轴箱或轮对数据。模型只覆盖上述转速递增试验条件；不能直接把它用于车辆状态诊断、维修决策、整车损坏、材料耐受极限或散架风险判断。

## 十一、批量导入 CSV

1. 点击“导入 CSV 工况”并选择 CSV 文件。
2. 文件须包含以下列名，列名区分大小写，首行必须是表头：
   name,mass_kg,initial_speed_kmh,braking_ratio,response_time_s,grade_permille,basic_resistance_coefficient,rotating_mass_factor,adhesion_coefficient
3. 每行代表一个工况。字段含义和单位与第六节一致。CSV 使用 UTF-8 或带 BOM 的 UTF-8 编码。
4. 可使用 `examples\braking_cases.csv`，或按车型选择 `examples\车型_*.csv`。新增样例包括城际/高速/市域动车组、A/B 型地铁、普速客车、重载敞车、铁路罐车、货运机车和调车机车，每个文件含 3 个速度或坡度工况。
5. 车型参数是课程演示用的示例假设，不代表特定铁路车辆的实车参数、型式试验数据或运营限值。
6. 导入后软件逐个计算工况。可计算的结果显示在结果表；无法计算的工况会在错误提示中列出。
7. CSV 缺少必需列、存在空字段、非数值数据或多余数据列时，导入会报错并指出无效行或缺失列。

## 十二、查看曲线

1. 完成计算后，在“工况”下拉框选择要查看的工况。
2. 在“曲线”下拉框选择“速度—时间”或“速度—距离”。
3. 横纵坐标单位显示在图表坐标轴上；图中速度单位为 km/h。
4. 曲线包含制动响应阶段和恒定减速度制动阶段。响应阶段按速度不变的简化假设绘制。

## 十三、导出结果

1. 当前至少有一组成功计算的结果时，点击“导出计算结果”。
2. 选择目标文件夹并输入文件名，软件保存为 CSV 格式。
3. 导出文件以 UTF-8 BOM 编码，方便常见电子表格软件打开。
4. 导出字段包括原始工况参数、计算减速度、制动力、黏着限制力、响应距离、制动距离、总停车距离、制动时间和总时间。
5. 仅导出成功计算的工况。没有结果时，软件会提示无法导出。

## 十五、模型与安全说明

计算中初速度由 km/h 换算为 m/s，线路坡度由 ‰ 换算为无量纲数值。程序假定制动率和基本运行阻力系数保持不变，忽略制动系统建立过程的连续变化、车辆间纵向冲动及制动系统温升。失控检测采用 β 与 μ 的比较及等效减速度正负判断；动画使用恒定加速度近似，不包含防滑控制、实时制动系统响应或多车辆动力学。合成 CNN 的标签为人为教学数据；公开数据 CNN 只分类实验台轴承的五种状态，不能推断铁路车辆或整车失效概率。检测报告不构成完整的轮轨黏着或制动系统校核。请勿将本软件计算结果用于实际铁路运营、安全判断或工程设计定型。
