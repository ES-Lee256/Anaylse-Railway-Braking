铁路车辆制动性能计算与分析程序

一、环境准备
1. 安装 Python 3.10 或更高版本。
2. 在项目根目录运行：
   python -m pip install -r need.txt
   python main.py

Tkinter、CSV 读写和数据模型使用 Python 标准库；NumPy 用于 CNN 与数值计算，SciPy 用于 MATLAB 振动数据读取和抗混叠降采样，Matplotlib 用于嵌入绘图。

二、运行测试
在项目根目录运行：
   python -m unittest discover -s tests -v

三、使用方法
1. 直接在主窗口修改车辆及工况参数，点击“计算当前参数”。
2. 点击“演示当前参数”播放车辆运动动画，结束后查看失控检测报告。
3. 点击“预测车辆状况（演示）”训练合成数据 1D CNN，并查看合成等级报告。
4. 点击“识别轴承状态（实测数据模型）”选择 `.mat` 文件，查看五类轴承状态的分类分数。
5. 点击“导入 CSV 工况”，选择 `examples\braking_cases.csv` 或 `examples\车型_*.csv` 中对应车型样例；每个车型文件含 3 组示例工况。
6. 计算成功的工况会显示在结果表，可在曲线区域切换工况和速度—时间、速度—距离曲线。
7. 点击“导出计算结果”保存有效工况的结果 CSV。

CSV 输入列及单位：
name：工况名称
mass_kg：车辆质量，kg
initial_speed_kmh：初速度，km/h
braking_ratio：制动率，无量纲
response_time_s：制动响应时间，s
grade_permille：线路坡度，‰，上坡为正、下坡为负
basic_resistance_coefficient：基本运行阻力系数，无量纲
rotating_mass_factor：旋转质量换算系数，无量纲
adhesion_coefficient：轮轨黏着系数，无量纲

`examples\车型_*.csv` 中车型参数是教学示例假设，不代表具体车辆实测值或运营限值。

四、模型说明
程序采用恒定制动率、恒定基本运行阻力系数和单车辆纵向运动的教学简化模型，忽略制动系统建立过程的动态变化、车辆间纵向冲动和制动系统温升。轮轨黏着检查采用制动率不大于黏着系数的简化判据。计算结果不能替代铁路车辆设计校核、运营规程或安全决策。

五、新版本失控检测
“演示当前参数”会按当前参数显示运动动画，并在结束后生成检测报告。制动率超过黏着系数时，演示将有效制动率限制为黏着系数并提示制动受限/滑移风险；正速度下等效减速度不大于 0 时，提示模型下无法停车并演示继续运行。此检测是教学用简化判断，不是实际车辆安全评估。

六、合成 CNN 状况等级演示
“预测车辆状况（演示）”会生成虚构时序样本并训练 1D 卷积网络。分类标签、耐受阈值和极端整体失效标签均由程序人为构造，不是基于真实损坏记录、试验或有限元数据。合成留出集准确率仅衡量模型复现合成标签的能力，不能用于预测真实车辆损伤或散架。

七、公开数据 CNN 轴承状态识别
数据来源为 Mendeley Data `Bearing Vibration Data under Time-varying Rotational Speed Conditions`（版本 2，DOI：10.17632/v43hmbwxpm.2，CC BY 4.0）。数据集共 60 条实验记录，覆盖健康、内圈故障、外圈故障、滚动体故障、复合故障五类及四种变速工况；本项目仅使用 A（转速递增）下每类三次试验，共 15 条。原始记录为 200 kHz、10 秒；只读取加速度 `Channel_1`，不使用编码器 `Channel_2`。

训练程序以完整试验为单位划分：每类 01、02 号共 10 条记录用于训练，03 号共 5 条记录留出验证。加速度用 SciPy 多相抗混叠滤波降采样至 20 kHz，按 512 点（25.6 ms）窗口、2048 点（102.4 ms）步长稀疏取窗；每个窗口形成 RMS 归一化波形和 `log10(RMS)` 两个特征通道，标准化统计量只由训练集估计。NumPy CNN 使用 12 个宽度为 5 的 1D 卷积滤波器、ReLU、全局平均池化及 softmax 分类层，以小批量梯度下降训练 80 轮。

本次留出验证含 490 个窗口，准确率为 62.86%（308/490）。复合故障 recall 为 36.73%，存在明显漏判；各类 precision/recall 和混淆矩阵见 `轴承CNN训练报告.txt`。这些窗口来自同一批实验记录，不能当作独立试验次数，验证结果也不能证明跨设备或跨工况泛化。数据是实验台轴承记录，不是铁路车辆轴箱/轮对数据；模型分数不是实际故障概率，不能用于铁路安全、维修、剩余寿命、整车失效或耐受极限判断。

需要重新下载数据并训练时，在 `newvers` 目录运行：
   python train_bearing_cnn.py

程序将核验数据集许可并用 SHA-256 校验下载文件，生成 `models\bearing_condition_v2.npz` 和 `轴承CNN训练报告.txt`。来源、署名和许可信息见 `data\mendeley_bearing_v2\ATTRIBUTION.txt`。PyInstaller 发行程序内嵌训练权重，不内嵌原始 `.mat` 文件。
